## ADDED Requirements

### Requirement: 大喜利中継の TUI 表示
TUI SHALL Ink を用いて、お題・各席の回答・審査結果・座布団台帳を中継台本風に表示しなければならない（MUST）。表示は engine が発行するイベントに基づき、回答が出揃う・裁定が下りる・台帳が更新される各タイミングを反映しなければならない（MUST）。

#### Scenario: ラウンドの進行を中継表示する
- **WHEN** engine がお題提示・回答・裁定・台帳更新のイベントを発行する
- **THEN** TUI はお題、各席の回答、座布団の増減、現在の台帳を順に画面へ反映する

#### Scenario: パスした席を表示する
- **WHEN** ある席が「パス」（失敗）になる
- **THEN** TUI はその席をパスとして示し、番組の表示を止めない

### Requirement: 人間によるお題投入
TUI SHALL 人間がお題を投入する手段として、自由入力・同梱お題リストからの選択・お任せ（自動選択）の 3 つを提供しなければならない（MUST）。MVP では人間の参加はお題側に限定し、回答席・審査席へは参加させてはならない（MUST NOT）。

#### Scenario: 自由入力でお題を投げる
- **WHEN** ユーザーが TUI でお題テキストを入力して確定する
- **THEN** TUI は入力をお題として engine に渡し、ラウンドを開始する

#### Scenario: お任せでお題を選ぶ
- **WHEN** ユーザーが「お任せ」を選ぶ
- **THEN** TUI は同梱リストからお題を自動選択して engine に渡す

#### Scenario: 人間は回答席に座れない
- **WHEN** MVP の番組を実行する
- **THEN** 回答席と審査席はすべて LLM が占め、人間が回答・審査として参加する手段は提供されない
